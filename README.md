# Global Happiness and Internet Penetration Analysis

## Project Overview & Data Sources
This repository contains the data processing pipeline and Tableau dashboard for our Business Intelligence assignment. We used Python to extract, clean, and transform four public datasets into a structured Star Schema. This data model allows us to analyze the factors driving global happiness and internet connectivity.

### Source Data
* [World Happiness Report (Historical)](https://www.kaggle.com/code/kanncaa1/world-happiness-expanatory-data-analysis/input?select=world-happiness-report.csv)
* [World Happiness Report 2021 (Used for regional indicators)](http://kaggle.com/datasets/ajaypalsinghlo/world-happiness-report-2021)
* [Number of Internet Users](https://www.kaggle.com/datasets/rosariomc/number-of-people-using-the-internet)
* [Global Population by Country (1950-2024)](https://www.kaggle.com/datasets/lucalullo/global-population-by-country-1950-2024)

*Note: The final transformed CSV files generated by our pipeline are saved in the `code_pipeline/output/` folder.*

## Pipeline Execution
To run the automated data pipeline and generate the Star Schema files, follow these steps:

1. Ensure Python and `pandas` are installed on your machine.
2. Download the source datasets from the links above and place them in the `data/` folder.
3. Open your terminal and navigate to the root directory of this repository.
4. Run the main script by executing:
   ```bash
   python pipeline/main.py
   ```
   *The script will process the raw data and output the final fact and dimension tables into the `pipeline/output/` directory.*

## Pipeline Breakdown
Here is exactly what `main.py` does to construct our Star Schema:

1. **Loading**: Reads the four raw CSV datasets into memory.
2. **Cleaning**: Drops rows with missing critical data (like year or country) and standardizes formatting.
3. **Building the 4 Dimensions**:
   * **Geography Dimension**: Extracts unique countries, assigns ISO codes, and maps them to their respective global regions.
   * **Date Dimension**: Creates a clean timeline for yearly analysis.
   * **Governance Dimension**: Categorizes nations based on their freedom and corruption scores.
   * **Economy Dimension**: Categorizes nations based on GDP per capita.
4. **Building the Fact Table**: Merges the quantitative metrics from all sources and links them to the dimension tables using generated surrogate keys. It also calculates a new measure: the `internet_penetration_rate`.

## Data Integration & Cleaning Challenges
We tried to keep manual data cleaning to an absolute minimum, as requested in the assignment instructions. However, integrating these four specific datasets presented a major challenge: the public sources used different spelling conventions for the same countries (e.g., "Czechia" in one file vs. "Czech Republic" in another, or different variations of the Congo). 

To fix this and successfully join the tables without losing data, we had to use a hardcoded dictionary (`NAME_FIX`). We mapped all anomalous country names to the exact spelling used in the primary World Happiness Report. This manual step was necessary to ensure accurate data integration across the different CSV files.

## Design Choices & Thresholds
To effectively answer our analytical questions in Tableau, we had to make a few design choices when deriving our dimension tables. We set specific cut-offs for our metrics:
* `CORRUPTION_HIGH = 0.75`
* `FREEDOM_HIGH = 0.75`
* `GDP_HIGH = 9.7`

We chose to bin these continuous variables into discrete tiers (High/Medium/Low) rather than leaving them as raw numbers in the dimension tables. This choice was tied directly to our analytical questions: it allows us to easily group countries in Tableau and clearly visualize how different tiers of governance quality and economic strength impact overall happiness and internet access.
